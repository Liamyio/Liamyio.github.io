# Liam 的嵌入式笔记 —— 使用说明

博客地址：**https://liamyio.github.io/**

这是一个 Hugo 静态博客，源码就放在这个仓库里。你不需要在自己电脑上装任何东西，
**所有操作都在 GitHub 网页上完成**：写完 Markdown 点提交，GitHub 会自动把网站
构建好并发布，一般 1 分钟内上线。

---

## 发表一篇新文章（全程网页操作）

1. 打开本仓库，进入 `content` → `posts` 文件夹
2. 点右上角 **Add file** → **Create new file**
3. 文件名填英文小写加连字符，以 `.md` 结尾，例如 `smart-car-motor-pid.md`
4. 把下面这段模板粘进去，改好标题、分类、标签，然后在横线下面写正文：

```markdown
---
title: "文章标题"
date: 2026-11-15T20:00:00+08:00
draft: false
categories: ["学习笔记"]
tags: ["STM32", "PID"]
description: "一句话摘要，会显示在文章列表和搜索结果里"
---

正文从这里开始，用 Markdown 写就行。
```

5. 页面拉到底，点 **Commit changes**
6. 等 1 分钟左右，刷新博客首页，新文章就出现了

> 想先存草稿：把模板里的 `draft: false` 改成 `draft: true`，草稿不会上线；
> 写完了再把文件打开改回 `false` 提交一次即可发布。

## 分类怎么选

- `智能车`：备赛系列（驱动、电机控制、视觉调试）
- `项目复盘`：一个项目从头到尾的完整记录
- `学习笔记`：其他所有学习记录、工具上手、读书笔记

标签随便加，中英文都行，例如 `ESP32`、`FOC`、`示波器`。

## 修改已发布的文章

在 `content/posts` 里点开文件 → 点右上角铅笔图标 → 改完拉到底 **Commit changes**。
改标题、改错别字、补内容都这么操作，提交后自动重新发布。

## 插入图片

1. 把图片传到 `static/images/` 文件夹（Add file → Upload files）
2. 正文里这样引用：`![图片说明](/images/图片文件名.png)`

## 查看发布状态

点仓库顶部的 **Actions** 标签：绿色对勾 = 发布成功；
红色叉 = 构建失败，点进去能看到原因（多半是 Markdown 头部模板格式写错，
比如少了引号或冒号后面没空格）。改好重新提交即可。

## 同步到 CSDN

个人博客是主阵地，CSDN 只是分发：把文章的 Markdown 原文复制到 CSDN 编辑器
（Markdown 模式）发一份即可，标题保持一致。掘金、知乎同理，不用全铺。

## 不要动的文件

- `themes/` —— 主题，动了容易把网站搞坏
- `.github/` —— 自动发布流水线
- `hugo.toml` —— 站点设置（改博客标题、简介、关于页菜单才需要动它，
  改之前先问 Muse）
